# Supermercado La Casona

## Descripción del proyecto

Supermercado La Casona es una aplicación web diseñada para facilitar la consulta de productos y la realización de pedidos en línea. El sistema permite a los usuarios explorar el catálogo, buscar productos, gestionar favoritos y agregar artículos al carrito de compras.

## Objetivo

Desarrollar una plataforma web que facilite la experiencia de compra de los clientes y permita mejorar la gestión de los productos y pedidos del supermercado.

## Funcionalidades principales

- Visualización del catálogo de productos.
- Búsqueda de productos.
- Navegación por categorías.
- Gestión de productos favoritos.
- Carrito de compras.
- Cálculo del total del pedido.
- Envío de pedidos mediante WhatsApp.
- Registro e inicio de sesión de usuarios.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git y GitHub
- Supabase
- Docker

## Estructura del proyecto

- `frontend/`: interfaz de usuario.
- `backend/`: lógica del servidor.
- `api/`: endpoints de la aplicación.
- `supabase/`: configuración de Supabase.
- `tests/`: pruebas del sistema.
- `.github/workflows/`: automatización de procesos.
